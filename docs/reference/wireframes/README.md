# Wireframes reference index

This directory stores visual reference artifacts that may help a future screen, modal, drawer, or responsive-state task.

No item in this directory overrides the official sources. Before implementing a visual surface, consult `docs/source-of-truth/CURRENT-DECISIONS.md`, the approved Implementation Plan, the App Flow, the UI/UX document, the applicable ADRs, and the Task Packet.

## Historical artifacts

- `historical/2026-09-25/` contains an imported low-fidelity catalog from the Product Owner. It is retained as historical visual evidence only and is not an implementation contract.

Reasons it is non-authoritative:

- it uses the historical CrewCommand brand;
- it contains SMS/Twilio material superseded by current decisions;
- it includes later-Epic integrations and flows;
- every use must be reconciled against the current Epic and approved Task Packet.
